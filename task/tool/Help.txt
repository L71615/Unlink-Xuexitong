一、准备工作

  1. 需要 Python 3.9 以上版本，并在项目目录执行：
       pip install -r requirements.txt

  2. 浏览器：推荐 Edge（项目里自带 msedgedriver.exe），也可以用 Chrome。
     使用 Chrome 时请确认驱动版本与浏览器版本一致。

  3. 首次运行先在「设置」页填好账号、密码、课程名称，点「保存设置」。


二、刷课

  1. 主页点「开始刷课」，程序会自动打开浏览器、登录、选课、逐个任务点往下刷。
  2. 运行日志会实时显示进度，异常行会标红。
  3. 想停下来点「结束」，或直接关闭窗口。
  4. 倍速建议 1–2 倍；倍速过高可能被平台判定异常，甚至清空已完成的任务点。

  5. 支持断点续刷：刷完的课程会自动标记，下次启动直接跳过；中途停下的课程会优先接着刷。
     断点记录在 task/tool/resume_state.json，可以在「刷课日志」页点「重置断点」清除。


三、答题

  1. 「章节测验」可选：DeepSeek AI / 随机答题 / 不刷题。
  2. 选 DeepSeek AI 需要填写 API Key，答案会先查本地缓存和免费题库，都没有才问 AI。
  3. 「答完题后」控制交卷策略：仅保存、强制提交，或答对率达到某个比例再提交。
  4. 答案仅供参考，尤其是简答、论述题，建议提交前自己看一眼。


四、签到

  1. 主页点「自动签到」，输入账号密码（或复用本地登录信息）。
  2. 程序每 7 秒检查一次课程里是否有进行中的签到，自动完成普通签到与位置签到。
  3. 滑块、人脸、拍照类签到需要手动完成。


五、定时与多端

  1. 「设置 → 定时刷课」可以设置每天自动开始与结束的时间，设置后需要保持窗口开着。
  2. 多端学习会同时跑多门课，容易触发风控或清空进度，除非实在刷不完不建议开启。


六、常见问题

  1. 点击开始没反应：确认已经在设置页保存过账号信息；必要时用管理员权限运行。
  2. 提示驱动版本不匹配：下载与浏览器版本一致的驱动，在设置页重新选择。
  3. 视频卡住不动：确认浏览器窗口没有被最小化；程序会自动刷新重试。
  4. 人脸认证弹窗：开启「跳过人脸」后仍失败时，按提示用手机扫码完成一次。
  5. 记录与缓存都在 task/record 里，可以在「刷课日志」「题库查询」页查看和清理。
